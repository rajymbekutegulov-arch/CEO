# ЕНТ · Школа №8

Платформа подготовки к ЕНТ для учеников школы №8: **география**, **математическая грамотность и математика**, **история Казахстана**. Объяснения, практика, тематические тесты, пробные варианты, личный прогресс и панель учителя — на русском и казахском языках.

Проект работает без npm-зависимостей и сборки. Нужен только Node.js 20+.

## Быстрый старт

```bash
npm start
```

Откройте **http://localhost:4173**.

При первом запуске создаётся `data/db.json` с демо-аккаунтами и стартовым курсом.

| Роль | Почта | Пароль |
| --- | --- | --- |
| Ученик | `student@school8.kz` | `student123` |
| Учитель | `teacher@school8.kz` | `teacher123` |

## Возможности

- 3 предмета, 13 тем, 134 вопроса с ответами и пояснениями.
- Путь обучения: урок → практика → тематический тест → пробный вариант ЕНТ.
- Регистрация, вход, личный кабинет, сохранение прогресса и результатов.
- Переключение RU/KZ во всём интерфейсе и учебных материалах.
- Панель учителя: предметы, темы, объяснения, вопросы, импорт/экспорт JSON.
- Адаптивная вёрстка и доступность (фокус, клавиатура, `prefers-reduced-motion`).
- Серверное хранение данных в `data/db.json`, scrypt-хэши паролей, HttpOnly-сессии.

## Структура

```
server/        HTTP-сервер, API, база, авторизация, seed-курс
public/        HTML, CSS, JS-приложение
scripts/       проверки контента и импортов, smoke-тест, сброс базы
data/          создаётся автоматически (db.json)
render.yaml    конфигурация для Render
DEPLOY.md      инструкция по деплою и разбор ERR_MODULE_NOT_FOUND
```

## Команды

| Команда | Назначение |
| --- | --- |
| `npm start` | запуск (перед стартом проверяются импорты) |
| `npm run dev` | запуск с авто-перезапуском |
| `npm run check` | проверка импортов и структуры курса |
| `npm run smoke` | 27 end-to-end проверок API |
| `npm run reset-db` | сброс базы к демо-состоянию с резервной копией |

## Деплой на Render

Подробная инструкция — в [DEPLOY.md](DEPLOY.md). Кратко:

- Root Directory: пусто (корень репозитория);
- Build Command: `npm install`;
- Start Command: `npm start`;
- Health Check Path: `/api/health`;
- приложение слушает `0.0.0.0` и порт из `PORT`.

Если ошибка `ERR_MODULE_NOT_FOUND` уже была, после обновления кода выполните **Clear build cache & deploy**.
